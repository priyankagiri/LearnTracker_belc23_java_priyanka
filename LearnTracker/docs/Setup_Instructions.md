# Setup Instructions

Jdk version : OpenJDK 17.0.20.1 for this project.
command to check version : java -version

```powershell
java -version
```


## Running "Hello World"

The code is in src/HelloWorld/HelloWorld.java.

To compile and run it, open PowerShell and run these commands:

```powershell
cd E:\LearnTracker\src\HelloWorld
javac HelloWorld.java
java HelloWorld
```


First, javac compiles HelloWorld.java into a .class file, then java executes it.
